# 🌤️ Weather App

A modern, responsive Weather Application built using **React**, **Vite**, **Bootstrap**, and the **OpenWeather API**. This application provides real-time weather information for any city in the world and automatically detects the user's current location using the browser's Geolocation API.

The app displays the current temperature, weather conditions, and a 5-day weather forecast with a clean and responsive user interface. It also changes the background dynamically based on the current weather conditions, creating a more interactive user experience.

---

## 🚀 Features

- 🌍 Search weather by city name
- 📍 Automatic current location detection
- 🌡️ Real-time temperature in Celsius
- ☁️ Weather description
- 📅 5-Day weather forecast
- 🎨 Dynamic background based on weather
- 📱 Fully responsive design
- ⚡ Fast performance with Vite
- ❌ Error handling for invalid city names

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Keerthi8970/weather-app.git
```

### Go to the project folder

```bash
cd weather-app
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open the browser and visit:

```
http://localhost:5173
```

---

## 📖 How to Use

1. Allow location access to view your local weather automatically.
2. Or enter any city name in the search box.
3. Click **Get Weather**.
4. View the current weather details and 5-day forecast.
